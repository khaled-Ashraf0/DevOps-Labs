# DevOps Labs & Case Studies

Hands-on practical labs, automation scripts, and infrastructure case studies completed during my DevOps Engineering training track *(actively updated as new modules are completed)*.

## Environments & Tools
* **Operating Systems:** Rocky Linux 9, Ubuntu Server (VMware Workstation)
* **Shell & Scripting:** Bash, Expect
* **Containerization & Orchestration:** Docker Engine, Dockerfile, Custom Bridge Networks *(Kubernetes — Upcoming)*
* **Core Services:** `systemd`, `firewalld`, `cron`, `atd`, Apache (`httpd`)
